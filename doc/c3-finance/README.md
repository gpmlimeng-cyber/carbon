## 页面结构

```
项目 → 资金（父页：总览 + 三账对账）
        ├─ 收入（按 WBS 加权进度确认）
        ├─ 开票（收款条件触发 → 可开票待办）
        └─ 回款（登记、建议核销、账龄）
```

## 关键设计

- **三个对象解耦可对账**：收入（权责发生）≠ 发票（纳税义务）≠ 回款（现金）；
- **应收不落库**：`发票 − 已核销` 用视图计算，账龄月末快照；
- **收入按 WBS 加权进度**：权重=预算成本，关键节点未过封顶 90%，每月存快照；
- **应收按收款条件节点**：`合同额 × 节点比例`，与收入的差 = 合同资产；
- **收款条件是触发器**：WBS 节点/事件/日期 → 生成可开票待办，不自动开票；
- **自动核销只做建议**：等额优先、到期日 FIFO，人工确认才落库。
